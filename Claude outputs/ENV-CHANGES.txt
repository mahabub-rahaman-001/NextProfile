# ---------- proxy / rate limiting ----------
# How many proxies sit in front of the app. The limiter reads the client
# address this many entries in from the RIGHT of X-Forwarded-For, so a
# caller cannot pick their own rate-limit key.
#   1 = Vercel, or a single nginx / load balancer   <- your deployment
#   2 = Cloudflare in front of your own proxy
#   0 = nothing in front; the header is ignored entirely
TRUSTED_PROXY_HOPS="1"

# Required on Vercel. Without it the limiter uses per-process memory,
# and every serverless invocation starts with an empty map -- which means
# no rate limiting at all. Upstash has a free tier.
# REDIS_URL="rediss://default:PASSWORD@HOST:PORT"

# ---------- email (Gmail / Google Workspace) ----------

#   myaccount.google.com -> Security -> 2-Step Verification -> App passwords
# Until SMTP_USER and SMTP_PASS are both filled in, the app logs the reset
# link in development and logs a clear error in production.
